# Avisos de componentes de terceiros

O Projetarium é desenvolvido com Flutter, Dart e pacotes de terceiros. Esses
componentes mantêm seus próprios direitos autorais e licenças; os termos do
Projetarium não substituem essas permissões.

Cada build Flutter gera o catálogo completo de avisos correspondente às
dependências realmente compiladas. No aplicativo, ele pode ser consultado em:

**Configurações > Sobre > Licenças de terceiros**

No bundle técnico, o mesmo catálogo é distribuído em
`data/flutter_assets/NOTICES.Z`. O instalador não deve remover ou substituir
esse arquivo.

Entre os componentes fundamentais estão:

- Flutter, licenciado pelos respectivos detentores sob BSD 3-Clause;
- Dart SDK, licenciado pelos respectivos detentores sob BSD 3-Clause;
- pacotes Flutter/Dart listados no catálogo gerado para a versão instalada;
- runtimes e bibliotecas nativas que acompanham o pacote Windows, conforme os
  avisos presentes no próprio artefato.

Para conferir uma licença específica, use a tela do aplicativo da mesma versão
instalada. Um inventário copiado de outra release pode não representar as
dependências efetivamente distribuídas.
